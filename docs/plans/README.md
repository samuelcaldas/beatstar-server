# Planos históricos

Os arquivos desta pasta são registros de planejamento. Eles preservam
contexto e decisões, mas não representam automaticamente o estado implementado.

- `hashed-jingling-crystal.md`: onboarding Android real; ainda contém etapas
  bloqueadas por evidência de cliente e assets.
- `unified-meandering-oasis.md`: autoria/exportação musical; a infraestrutura
  atual cobre apenas parte do escopo e não comprova playback nativo.

Critérios de aceite de um plano devem ser confirmados contra `docs/sot/`, o
código e os testes antes de serem tratados como concluídos.
